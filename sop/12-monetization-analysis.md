# 12 商业化路径分析

## 目标

根据项目价值、用户画像和产品形态，判断可行的变现方式。

## 必读资源

- `strategies/monetization-strategy.md`
- `prompts/monetization-prompt.md`

## 变现类型

- 订阅付费
- 按次付费
- 模板或资源包售卖
- 企业定制
- API 调用计费
- 增值服务
- 内容引流
- 课程或训练营

## 执行步骤

1. 判断项目更适合直接收费还是先内容引流。
2. 给出首选变现方式和备选方式。
3. 说明定价依据和付费触发点。
4. 给出最小商业验证动作。

## 质检

- 不能只写“可以做 SaaS 订阅”，必须说明用户为什么付费。
- 变现方式必须和 MVP 形态一致。

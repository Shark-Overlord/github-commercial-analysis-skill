# GitHub 搜索策略

## 关键词生成

关键词应覆盖三类意图：

- 能力词：`ai agent`、`automation`、`workflow`、`image editor`、`video generator`、`data extraction`
- 用户词：`creator`、`developer tool`、`marketing`、`productivity`、`small business`
- 形态词：`web app`、`browser extension`、`desktop app`、`api`、`dashboard`

## 搜索组合

- 用英文关键词搜索 GitHub，因为开源项目主要使用英文描述。
- 对中文市场机会，可加入 `wechat`、`douyin`、`xiaohongshu`、`chinese`、`localization` 等词。
- 对开发者工具，可加入 `cli`、`sdk`、`self-hosted`、`open source`。

## 排除词

默认排除：

- `malware`
- `exploit`
- `crack`
- `bypass`
- `phishing`
- `stealer`
- `spam`

## 排序策略

- 第一轮按相关性和 Star 获取候选。
- 第二轮按最近更新、README 清晰度、产品场景和风险过滤。
- 最终排序不直接按 Star，必须加入用户匹配度和商业化潜力。

# 产品形态映射表

| 项目类型 | 首选形态 | 备选形态 |
| --- | --- | --- |
| AI 生成工具 | Web 工具站 | SaaS、内容选题、API 服务 |
| 浏览器自动化 | 浏览器插件 | 桌面软件、企业流程工具 |
| 数据抓取与整理 | Web 工具站 | 企业定制、自动化脚本 |
| 开发者库 | API 服务 | 教程案例、模板资源包 |
| 可视化组件 | 模板资源包 | SaaS、内容选题 |
| 本地桌面工具 | 桌面软件 | Web 轻量版、教程案例 |
| Agent 工作流 | SaaS 产品 | 企业解决方案、内容案例 |
| 文档处理工具 | Web 工具站 | 插件、企业定制 |

## 判断原则

- 普通用户优先 Web 工具站或小程序。
- 开发者用户优先 API、CLI、模板和教程。
- 企业用户优先 SaaS、私有化和解决方案。
- 展示效果强但付费弱的项目优先内容选题。

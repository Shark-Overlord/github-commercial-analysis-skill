# 10 产品形态判断

## 目标

根据项目能力、用户画像、复刻难度和商业化方向，判断最适合的产品形态。

## 必读资源

- `strategies/packaging-strategy.md`
- `assets/product-type-map.md`

## 候选形态

- Web 工具站
- SaaS 产品
- 微信小程序
- 浏览器插件
- 桌面软件
- API 服务
- 自动化脚本
- 模板资源包
- 内容账号选题
- 课程或教程案例
- 企业解决方案

## 执行步骤

1. 判断项目核心价值是“工具能力”“流程能力”“数据能力”“内容能力”还是“基础设施能力”。
2. 根据用户画像筛选可执行的产品形态。
3. 给出首选形态和备选形态。
4. 说明为什么不推荐其他形态。

## 质检

- 产品形态必须和用户资源匹配。
- 面向普通用户的形态要降低安装、配置和部署门槛。

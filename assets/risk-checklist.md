# 风险排查清单

## 必查项

- 是否有 License？
- License 是否允许目标商业用途？
- 是否使用第三方模型、权重、数据集、图片、字体或品牌素材？
- 是否涉及用户隐私、账号、Cookie、Token 或敏感数据？
- 是否可能违反平台规则？
- 是否涉及攻击、破解、绕过、钓鱼、批量骚扰或垃圾信息？
- 是否长期无人维护？
- 是否部署成本明显高于用户预算？
- 是否依赖不可控的海外服务？

## 高风险信号

- README 中出现 bypass、crack、exploit、phishing、stealer 等用途。
- 无 License 但计划商用。
- 项目依赖来源不明的数据或模型。
- 项目需要采集第三方平台账号或 Cookie。
- 原项目品牌、Logo 或素材不可复用。

## 输出要求

每个项目至少输出一个风险结论。没有发现明显风险时，也要写“未发现明显高风险，但仍需正式商用前复核 License 和依赖来源”。

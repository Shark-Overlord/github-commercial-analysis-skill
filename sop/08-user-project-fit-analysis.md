# 08 用户-项目匹配分析

## 目标

判断项目是否适合当前用户，而不是只判断项目本身是否热门。

## 必读资源

- `strategies/user-project-match-strategy.md`
- `criteria/user-project-fit-criteria.md`
- `prompts/user-project-fit-prompt.md`

## 匹配维度

- 技术能力匹配
- 时间预算匹配
- 资金预算匹配
- 目标市场匹配
- 目标产出匹配
- 内容平台匹配
- 变现偏好匹配
- 风险承受能力匹配
- 是否能利用用户已有资源

## 执行步骤

1. 将用户画像和项目特征逐项对照。
2. 对每个项目给出匹配分、主要匹配点和主要不匹配点。
3. 对不匹配但仍有价值的项目给出降级包装建议。
4. 将匹配结果传递给商业化和 MVP 阶段。

## 质检

- 不允许脱离用户画像推荐项目。
- 推荐理由必须解释“为什么适合这个用户”。
- 匹配低的项目即使商业潜力高，也不能给最高推荐等级。
